<objective>
Implement `runPostPhasePipeline()` orchestrator and `spawnStep()` helper in `lib/autopilot.ts`.
The orchestrator runs 4 sequential steps: simplify → PR creation → code review → rebase+merge.
Each step gets its own timeout. On failure at any step, stops and reports which step failed.
Rebase conflicts trigger a conflict-resolve subprocess. Non-zero subprocess exit halts pipeline.
`pushAndCreatePR()` is reused from `lib/worktree.ts`.
`--skip-post-pipeline` flag bypasses all four steps.
</objective>

<task id="3" type="auto">
<name>Implement runPostPhasePipeline orchestrator</name>
<description>
Add `runPostPhasePipeline(cwd, phaseNum, wtPath, opts)` that executes:
1. Simplify — spawn subprocess with buildSimplifyPrompt
2. PR creation — call pushAndCreatePR from lib/worktree.ts
3. Code review — spawn subprocess with buildCodeReviewPrompt(prUrl)
4. Rebase+merge — git rebase main, on conflict spawn buildConflictResolvePrompt,
   force-push rebased branch, merge PR via gh CLI

Each step returns on failure with step name and reason.
</description>
<done_criteria>
- All 4 steps execute sequentially
- Failure at any step halts and reports step name
- Rebase conflicts trigger subprocess
- Non-zero conflict resolution exit halts pipeline
- PR merged via gh pr merge on success
</done_criteria>
</task>
