         b. `## Phase Goal` — read from ROADMAP.md by finding the phase entry (use `options.phase`), extract goal text. If not found, omit section.
         c. `## Plan Summary` — read from the active PLAN.md in the phase directory. Extract the `<objective>` content. If not found, omit section.
         d. `## Recent Changes` — run `execFileSync('git', ['diff', '--stat', 'HEAD~3..HEAD'], ...)` to get recent change summary. Truncate to 2K chars.
         e. `## Project State` — read STATE.md current position section. Truncate to 1K chars.
       - Total output must stay under 8K tokens (~32K chars). Apply truncation to each section with a budget: question (1K), phase goal (1K), plan summary (2K), recent changes (2K), project state (1K). Remaining budget for headers/formatting.

       - Use the existing `paths` module pattern if available, or construct paths manually from cwd + `.planning/`.

    2. Implement `resolveElicitation(question: string, context: string, options: { participants: BackendId[]; synthesizer: BackendId; cwd: string }): string`:
       - Build a discussion prompt: combine `context` with instruction to answer the question concisely and make a decision (not ask more questions).
       - Call `runDiscussion()` with:
         - `topic`: the question
         - `participants`: from options
         - `rounds`: 1 (speed over depth)
         - `synthesizer`: from options
         - `cwd`: from options
         - `type`: 'elicitation'
       - Extract and return `result.synthesis.response_text` (trimmed).
       - Edge cases:
         a. If `runDiscussion()` throws or returns null synthesis: iterate `result.rounds[0]` to find the first non-skipped entry and return its `response_text`. If all skipped, return `''`.
         b. If all participants are unavailable (empty rounds): return `''`.
       - The function should be synchronous (matching existing discussion.ts patterns — `execFileSync` based).

    3. Add both functions to `module.exports` at the bottom of `lib/discussion.ts`.

    Avoid: Do not introduce async patterns — the existing module is synchronous. Do not read files outside `.planning/` directory. Do not make the context builder dependent on specific ROADMAP.md formatting beyond what already exists in the codebase.
