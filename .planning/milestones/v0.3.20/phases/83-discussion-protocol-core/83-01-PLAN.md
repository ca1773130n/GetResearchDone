    2. `DiscussionResult` — An interface with exactly these fields:
       - `topic: string` — The topic/question posed to all participants
       - `participants: BackendId[]` — Backend IDs of all requested participants (including skipped)
       - `rounds: DiscussionRoundEntry[][]` — Per-round array of participant responses. rounds[0] = round 1, etc.
       - `synthesis: BackendResponse` — Synthesizer backend response after round 1 collection
       - `duration_ms: number` — Total wall-clock duration in milliseconds
       - `discussion_file: string` — Absolute path to the written markdown history file

       - `cwd?: string` — default process.cwd()
       - `phase?: string` — for filename, default 'unknown'
       - `type?: string` — for filename, default 'discussion'
       - `milestone?: string` — for path, default currentMilestone(cwd)
