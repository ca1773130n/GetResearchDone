    **2. buildSynthesisPrompt(topic, roundEntries)** — Internal helper (not exported).
    Takes the original topic and round 1 entries. Returns a prompt string for the synthesizer:
    ```
    You are synthesizing responses from multiple AI backends on the following topic:

    ## Topic
    {topic}

    ## Responses

    ### {backend} Response
    {response_text}
    (or "[SKIPPED]" for skipped entries)

    ## Instructions
    Synthesize the above responses. Identify areas of consensus, disagreement, and unique insights. Provide a unified recommendation.
    ```

    **3. buildDiscussionMarkdown(result)** — Internal helper (not exported).
    Takes a DiscussionResult and returns a markdown string. Format:
    ```
    # Discussion: {topic}

    **Phase:** {phase}  **Type:** {type}  **Participants:** {participants}
    **Synthesizer:** {synthesis.backend}  **Rounds:** {rounds.length}  **Duration:** {duration_ms}ms
    **Timestamp:** {ISO date}

    ## Round 1
    ### {backend} Response
    {response_text or "[SKIPPED: reason]"}
    ---

    ## Synthesis ({synthesis.backend})
    {synthesis.response_text}

    ## Round 2 (if exists)
    ### {backend} Response
    {response_text or "[SKIPPED: reason]"}
    ---

    ## Outcome
    {synthesis.response_text}
    ```
    Pass `phase` and `type` as extra parameters or extract from the filename.

    **4. runDiscussion(topic, participants, options?)** — The main exported async function.
    Implementation steps:
    a. Destructure options with defaults: rounds=2 (clamped 1-3), synthesizer='claude', timeout=180, cwd=process.cwd(), phase='unknown', type='discussion', milestone=null
    b. Clamp rounds: `const clampedRounds = Math.min(Math.max(rounds, 1), 3);`
    c. Record start time: `const start = Date.now();`
    d. Get availability: `const availability = detectAvailableBackends(cwd);`
    e. Build discussion filename: `discussion-${phase}-${type}-${Date.now()}.md`
    f. Resolve discussions dir via `discussionsDir(cwd, milestone)`

    **Round 1 — Parallel dispatch:**
    Use `Promise.allSettled()` with one promise per participant. Each promise:
    - Checks `availability[participant]?.available` — if false, resolve with `{ backend: participant, skipped: true, reason: 'Backend "X" is not available' }`
    - If available, try `dispatchToBackend(participant, topic, { timeout_ms: timeout * 1000, cwd })` — on catch, resolve with `{ backend: participant, skipped: true, reason: String(err) }`
    Map settled results: fulfilled → value, rejected → `{ backend: 'unknown' as BackendId, skipped: true, reason: String(reason) }`

    **Synthesis:**
    Build synthesis prompt via `buildSynthesisPrompt(topic, round1Results)`.
    Call `dispatchToBackend(synthesizer, synthPrompt, { timeout_ms: timeout * 1000, cwd })`.

    **Round 2+ (when clampedRounds >= 2):**
    For each subsequent round:
    - Build a round prompt that includes the synthesis text and asks participants to respond to it
    - Fan out to all participants again with `Promise.allSettled()` (same skip-checking pattern)
    - Collect results into the rounds array

    **Write history file (BEFORE return):**
    ```typescript
    const filePath = path.join(dir, filename);
    fs.mkdirSync(dir, { recursive: true });
    ```
    Build the result object, then write markdown synchronously:
    ```typescript
    fs.writeFileSync(filePath, buildDiscussionMarkdown(result, phase, type), 'utf-8');
    ```

    **Return:** `DiscussionResult` with all fields populated including `discussion_file: filePath`.

    NOTE on true parallelism: `execFileSync` blocks the event loop, so wrapping in Promise.allSettled() provides structural concurrency but not OS-level parallelism. This is acceptable for ≤4 participants. Add a JSDoc note documenting this limitation.

    **5. listDiscussions(cwd, milestone?)** — Exported function.
    Returns array of filenames from `discussionsDir(cwd, milestone)`. If directory doesn't exist, return empty array.

    **6. readDiscussion(filename, cwd, milestone?)** — Exported function.
    Returns the UTF-8 content of a specific discussion file from the discussions directory. If file doesn't exist, return null.

    **7. Update module.exports:**
    Add `runDiscussion`, `listDiscussions`, `readDiscussion` to the existing exports block. Do NOT export buildSynthesisPrompt or buildDiscussionMarkdown (internal helpers).

    **Avoid:**
    - Using `any` anywhere — all types must be explicit
    - Sequential for-loop dispatch — always use Promise.allSettled()
    - Writing the file after returning — must be synchronous before the return statement
    - Hardcoding discussion directory path — use discussionsDir() from lib/paths.ts
    - Forgetting to add new functions to module.exports
