<task type="auto">
  <name>Task 2: Extend config loading and add backend availability detection</name>
  <files>lib/utils.ts, lib/backend.ts</files>
  <action>
    **In lib/utils.ts:**
    1. Add 'backend_roles' and 'discussion' to `KNOWN_CONFIG_KEYS` Set.
    2. In `loadConfig()`, after existing field extraction, add:
       - Read `backend_roles` from parsed config. Validate each value is in VALID_BACKENDS (import from backend.ts). Warn on stderr and skip invalid entries. Store as `BackendRolesConfig | undefined`.
       - Read `discussion` from parsed config. Validate: `enabled` is boolean, `max_rounds` is number clamped 1-3, `timeout_per_round_seconds` is positive number, `synthesizer` is in VALID_BACKENDS. Store as `DiscussionConfig | undefined`, merging with defaults.
    3. Return both new fields in the GrdConfig result.

    **In lib/backend.ts:**
    1. Import `BackendAvailability` type from `./types`.
    2. Add a module-level `_availabilityCache` (same pattern as `_modelCache`):
       ```
       interface AvailabilityCacheEntry { result: Record<BackendId, BackendAvailability>; ts: number }
       let _availabilityCache: AvailabilityCacheEntry | null = null;
       const AVAILABILITY_CACHE_TTL_MS: number = 5 * 60 * 1000;
       ```
    3. Implement `detectAvailableBackends(cwd?: string): Record<BackendId, BackendAvailability>`:
       - Check cache first (same TTL pattern as getCachedModels).
       - For each of the four dispatchable backends ('claude', 'codex', 'gemini', 'opencode'):
         - Use `execFileSync(binary, ['--version'], { timeout: 5000, encoding: 'utf-8', stdio: ['pipe','pipe','pipe'] })` wrapped in try/catch.
         - For claude: binary is 'claude', args ['--version'].
         - For codex: binary is 'codex', args ['--version'].
         - For gemini: binary is 'gemini', args ['--version'].
         - For opencode: binary is 'opencode', args ['--version'].
         - On success: `{ available: true, version: stdout.trim().split('\n')[0] }`.
         - On error: `{ available: false, version: null }`.
       - Skip 'overstory', 'superpowers', 'grd' (not dispatchable CLIs) — set all to `{ available: false, version: null }`.
       - Cache result and return.
    4. Export `detectAvailableBackends` and add `clearAvailabilityCache` for testing.
    5. Add `clearAvailabilityCache` to module.exports.
  </action>
