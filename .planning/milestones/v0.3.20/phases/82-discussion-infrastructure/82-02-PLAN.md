       - `const { detectAvailableBackends } = require('./backend') as { detectAvailableBackends: ... }`

    3. Constants:
       - `const DISCUSSION_SONNET_MODEL: string = 'sonnet'` — mirrors the pattern from lib/wireup/state.ts and lib/evolve/state.ts. This is the ceiling for primary-backend discussion subagent spawns (REQ-149).
       - `const DEFAULT_DISPATCH_TIMEOUT_MS: number = 5 * 60 * 1000` — 5 minutes default.
       - `const BACKEND_CLI_MAP` — Record mapping BackendId to its CLI binary name and argument builder:
         ```
         claude: { bin: 'claude', buildArgs: (prompt, model?) => ['--print', '-p', prompt, ...(model ? ['--model', model] : [])] }
         codex: { bin: 'codex', buildArgs: (prompt, _model?) => ['-q', prompt] }
         gemini: { bin: 'gemini', buildArgs: (prompt, _model?) => [prompt] }
         opencode: { bin: 'opencode', buildArgs: (prompt, _model?) => [prompt] }
         ```
         Only include the four dispatchable backends. Type the map as `Record<string, { bin: string; buildArgs: (prompt: string, model?: string) => string[] }>`.

    4. Function `dispatchToBackend(backendId: BackendId, prompt: string, options?: DispatchOptions): BackendResponse`:
       - Validate backendId is in BACKEND_CLI_MAP. If not, return error response: `{ backend: backendId, response_text: '', duration_ms: 0, stderr: 'Backend "${backendId}" is not dispatchable' }`.
       - Check availability via detectAvailableBackends(). If target backend is not available, return error response with stderr indicating unavailability.
       - Build CLI args using BACKEND_CLI_MAP.
       - Record start time with `Date.now()`.
       - Execute using `execFileSync(bin, args, { timeout: options?.timeout_ms ?? DEFAULT_DISPATCH_TIMEOUT_MS, encoding: 'utf-8', cwd: options?.cwd ?? process.cwd(), stdio: ['pipe', 'pipe', 'pipe'], maxBuffer: 10 * 1024 * 1024 })`.
       - On success: return `{ backend: backendId, response_text: stdout.trim(), duration_ms: Date.now() - start, stderr: '' }`.
       - On timeout (check error.killed or error.signal === 'SIGTERM'): return `{ backend: backendId, response_text: '', duration_ms: Date.now() - start, stderr: 'Dispatch timed out after ${timeout}ms' }`.
       - On other error: return `{ backend: backendId, response_text: '', duration_ms: Date.now() - start, stderr: error.stderr || error.message }`.

    5. Module exports: `{ dispatchToBackend, DISCUSSION_SONNET_MODEL, BACKEND_CLI_MAP, DEFAULT_DISPATCH_TIMEOUT_MS }`.

    Follow the codebase convention: every variable has an explicit type annotation, no `any`, prefix unused args with `_`.
