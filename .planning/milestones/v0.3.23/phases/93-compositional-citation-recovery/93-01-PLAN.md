<task type="auto">
  <name>Task 1: Add citation graph type definitions to lib/types.ts</name>
  <files>lib/types.ts</files>
  <action>
    Add a new section `// ─── Citation Types (from citations.ts) ────────────────────────────────────` before the `module.exports = {};` line at the bottom of lib/types.ts.

    Define the following interfaces:

    1. **MissingComponent** — a component referenced but not implemented in the paper:
       - `name: string` — component identifier
       - `source_paper: string` — paper slug or title where component originates
       - `description: string` — what the component does
       - `code_available: boolean` — whether source code exists for this component

    2. **BorrowedComponent** — a component adopted from another paper:
       - `name: string` — component identifier
       - `source_paper: string` — paper slug or title
       - `description: string` — what the component does

    3. **CitationNode** — a node in the citation graph:
       - `slug: string` — paper slug (e.g., "vaswani-attention-2017")
       - `title: string` — full paper title
       - `resolved: boolean` — whether the paper has been fetched and analyzed
       - `priority: 'critical' | 'normal' | 'low'` — how important this dependency is
       - `technique_summary: string` — extracted technique description (empty until resolved)
       - `missing_components: MissingComponent[]`
       - `borrowed_components: BorrowedComponent[]`

    4. **CitationEdge** — a directed edge in the graph:
       - `from_slug: string` — paper that depends on another
       - `to_slug: string` — paper being depended upon
       - `type: 'missing' | 'borrowed'` — whether this is a missing or borrowed dependency
       - `component_name: string` — which component creates this edge

    5. **CitationGraph** — the complete graph:
       - `nodes: CitationNode[]`
       - `edges: CitationEdge[]`
       - `built_at: string` — ISO timestamp of graph construction

    6. **ApiConfig** — configuration for citation resolution APIs:
       - `arxiv_enabled: boolean`
       - `semantic_scholar_enabled: boolean`
       - `timeout_ms: number`

    Export all interfaces with `export interface`.
  </action>
  <verify>npm run build:check</verify>
  <done>All six citation interfaces exist in lib/types.ts, TypeScript compiles cleanly</done>

<task type="auto">
  <name>Task 2: Create lib/citations.ts with buildCitationGraph function</name>
  <files>lib/citations.ts</files>
  <action>
    Create `lib/citations.ts` following the project's CommonJS pattern (`'use strict'`, typed requires, module.exports).

    **Imports:**
    ```typescript
    import type { CitationGraph, CitationNode, CitationEdge, MissingComponent, BorrowedComponent } from './types';
    const fs = require('fs') as typeof import('fs');
    const path = require('path') as typeof import('path');
    const { safeReadFile } = require('./utils') as { safeReadFile: (p: string) => string | null };
    ```

    **parseMissingComponents(content: string): MissingComponent[]**
    - Find `## Missing Components` or `### Missing Components` section in PAPERS.md entry content
    - Parse structured entries. Each entry follows the format:
      ```
      - **name:** ComponentName
        - source_paper: paper-slug-or-title
        - description: What the component does
        - code_available: true|false
      ```
    - Also support table format: `| name | source_paper | description | code_available |`
    - Return array of MissingComponent objects

    **parseBorrowedComponents(content: string): BorrowedComponent[]**
    - Find `## Borrowed Components` or `### Borrowed Components` section
    - Parse same structured list or table format (without code_available field)
    - Return array of BorrowedComponent objects

    **buildCitationGraph(papersDir: string): CitationGraph**
    - Read all `PAPERS.md` files in papersDir (use glob pattern or readdir)
    - For each PAPERS.md, split into individual paper entries (split on `## ` or `### ` headings that look like paper titles)
    - Extract paper slug from heading (lowercase, hyphenated)
    - Call parseMissingComponents and parseBorrowedComponents for each entry
    - Build CitationNode for each paper entry with resolved:false initially, priority:'normal'
    - Build CitationEdge for each missing_component (type:'missing') and borrowed_component (type:'borrowed')
    - For missing components where code_available is false, set the target node's priority to 'critical' if the node exists
    - Store per-paper JSON to `{papersDir}/../citations/{paper-slug}.json` using `fs.mkdirSync` with recursive:true
    - Return the complete CitationGraph with built_at timestamp

    **Export:** `module.exports = { buildCitationGraph, parseMissingComponents, parseBorrowedComponents };`

    Follow code style: zero `any`, prefix unused args with `_`, use `Record<string, unknown>` where needed.
  </action>
