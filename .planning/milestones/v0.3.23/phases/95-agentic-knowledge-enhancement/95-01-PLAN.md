<task type="auto">
  <name>Task 2: Create lib/knowledge.ts with four core functions</name>
  <files>lib/knowledge.ts</files>
  <action>
    Create `lib/knowledge.ts` following the project's CommonJS pattern (`'use strict'`, typed requires, module.exports).

    **Imports:**
    ```typescript
    import type { KnowhowEntry } from './types';
    const fs = require('fs') as typeof import('fs');
    const path = require('path') as typeof import('path');
    ```

    **formatKnowhowEntry(entry: KnowhowEntry): string**
    - Convert a KnowhowEntry to a markdown block:
      ```
      ### {pattern_name}

      - **source:** {source}
      - **applicability:** {applicability}
      - **code_snippet:** {code_snippet}
      - **phase_number:** {phase_number}
      - **created_at:** {created_at}
      ```
    - Return the markdown string (no trailing newline beyond one blank line separator)

    **parseKnowhowEntries(content: string): KnowhowEntry[]**
    - Parse KNOWHOW.md content into an array of KnowhowEntry objects
    - Split on `### ` headings (level-3)
    - For each heading block, extract pattern_name from the heading text
    - Parse structured fields: source, applicability, code_snippet, phase_number, created_at
    - Use regex to match `- **field:** value` pattern
    - phase_number should be parsed as number (parseInt)
    - Return empty array for empty/missing content
    - Must roundtrip with formatKnowhowEntry — parse(format(entry)) === entry

    **appendKnowhowEntries(knowhowPath: string, entries: KnowhowEntry[]): void**
    - Read existing KNOWHOW.md at knowhowPath (or start with empty string if file doesn't exist)
    - Parse existing entries with parseKnowhowEntries
    - Deduplicate: if a new entry has the same pattern_name as an existing one, keep the newer one (higher phase_number)
    - Format all entries and write back to knowhowPath
    - Ensure the file starts with `# KNOWHOW\n\n` header
    - Create parent directories if needed (fs.mkdirSync with recursive)

    **selectTopEntries(entries: KnowhowEntry[], n: number, moduleHints?: string[]): KnowhowEntry[]**
    - Return top-N entries from the input array
    - Primary sort: phase_number descending (most recent first)
    - If moduleHints provided: entries whose source or applicability mentions any hint get a boost (sorted first among same-phase entries)
    - Return at most n entries
    - If entries.length <= n, return all entries sorted

    **module.exports:**
    ```typescript
    module.exports = {
      formatKnowhowEntry,
      parseKnowhowEntries,
      appendKnowhowEntries,
      selectTopEntries,
    };
    ```
  </action>
  <verify>npm run build:check && npm run lint</verify>
  <done>lib/knowledge.ts exists with all four functions exported; TypeScript compiles and lint passes</done>
</task>
