  <name>Task 2: Add knowledge mining step to lib/autopilot.ts</name>
  <files>lib/autopilot.ts</files>
  <action>
    Add the knowledge mining step in `runAutopilot()` between execute completion and post-pipeline launch.

    **Location:** After `writeStatusMarker(cwd, task.phaseNum, 'execute', 'completed')` (around the line that logs "execute completed") and before the `if (!skipPostPipeline)` block.

    **New function `buildKnowledgeMiningPrompt(phaseNum: string): string`:**
    - Returns a prompt string instructing the knowledge miner agent to:
      - Read phase SUMMARY.md files
      - Analyze code changes and decisions
      - Produce ---KNOWHOW-ENTRY--- blocks
      - Write entries to KNOWHOW.md via appendKnowhowEntries

    **New function `runKnowledgeMining(cwd: string, phaseNum: string, wtPath: string, options: { scheduler?: any; log: (...args: any[]) => void }): Promise<void>`:**
    - Check if `agents/grd-knowledge-miner.md` exists (use path.resolve with the main cwd, not worktree)
    - If agent def doesn't exist: log "Knowledge mining skipped — agent definition not found", call writeStatusMarker with 'skipped', return
    - If exists: writeStatusMarker 'started', spawn agent with buildKnowledgeMiningPrompt, writeStatusMarker 'completed'
    - Wrap the spawn call in try/catch — on error: log warning, writeStatusMarker 'failed', do NOT re-throw (pipeline continues)

    **Integration point in runAutopilot:**
    After execute completes successfully for a phase, before launching post-pipeline:
    ```typescript
    // Knowledge mining (non-blocking — failure does not halt pipeline)
    try {
      await runKnowledgeMining(cwd, task.phaseNum, wtPath, { scheduler, log });
    } catch (_err) {
      log(`Phase ${task.phaseNum}: knowledge mining error (non-blocking)`);
    }
    ```

    **Export** `runKnowledgeMining` and `buildKnowledgeMiningPrompt` from module.exports.
  </action>
  <verify>npm run build:check && npm run lint</verify>
  <done>lib/autopilot.ts has knowledge mining step that is non-blocking and backward compatible</done>
