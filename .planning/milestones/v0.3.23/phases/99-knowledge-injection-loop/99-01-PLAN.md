    ```typescript
    function buildKnowledgeInjectionBlock(
      cwd: string,
      _phaseNum: string,
      moduleHints?: string[],
    ): string
    ```

    Implementation:
    1. Read KNOWHOW.md from `path.join(cwd, 'KNOWHOW.md')` using `safeReadFile` (already imported).
    2. If content is null or empty after trim, return `''`.
    3. Parse entries via `parseKnowhowEntries(content)`.
    4. If entries array is empty, return `''`.
    5. Select top 5 via `selectTopEntries(entries, 5, moduleHints)`.
    6. Format each selected entry via `formatKnowhowEntry(entry)`.
    7. Return a string in this format:
       ```
       <knowhow_context>
       The following patterns were mined from prior phase executions. Apply relevant ones:

       {formatted entries joined by newlines}
       </knowhow_context>
       ```

    Add `buildKnowledgeInjectionBlock` to the `module.exports` object.

    Note: `_phaseNum` is prefixed with underscore because it is reserved for future use (phase-proximity scoring) but not used in the initial implementation. This avoids the ESLint `no-unused-vars` error.
