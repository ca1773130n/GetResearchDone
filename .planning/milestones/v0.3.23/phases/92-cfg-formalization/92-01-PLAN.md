<task type="auto">
  <name>Task 2: Create lib/invariants.ts with all five validation functions</name>
  <files>lib/invariants.ts</files>
  <action>
    Create `lib/invariants.ts` following the project's CommonJS pattern (`'use strict'`, typed requires, module.exports).

    **extractPlanArtifact(content: string): PlanArtifact**
    - Use extractFrontmatter from lib/frontmatter.ts to parse YAML frontmatter
    - Extract `<objective>` tag content via regex
    - Return typed PlanArtifact with defaults for missing fields (empty arrays, empty strings)

    **validateStructural(plan: PlanArtifact): ValidationResult**
    - Error if objective is empty/missing
    - Error if files_modified is not an array or is empty
    - Error if wave is not a positive integer
    - Error if autonomous is not boolean
    - Error if type is empty
    - Warning if depends_on is not an array
    - Warning if provides/requires are empty arrays (informational)
    - Return {valid: errors.length === 0, errors, warnings}

    **validateSemantic(plan: PlanArtifact, cwd: string): ValidationResult**
    - Error if any file path is absolute (starts with /)
    - Error if any file path contains .. traversal
    - Warning if file paths lack extensions
    - Warning if objective doesn't reference any known lib/ module or directory
    - Use fs.existsSync sparingly — only check parent directories exist, not individual files

    **validateCrossPhase(plans: PlanArtifact[]): ValidationResult**
    - Error if multiple plans provide the same artifact string
    - Error if a plan requires something no plan provides
    - Warning if provides/requires arrays are all empty (no dependency tracking)

    **validateResearchArtifacts(phaseDir: string): ValidationResult**
    - Check if LANDSCAPE.md exists in research dir — if yes, verify it has `|` table rows
    - Check if PAPERS.md exists — if yes, verify structured headings (# or ##)
    - Check if RESEARCH.md exists — if yes, verify `## Method` and `## Tradeoffs` sections
    - Files not existing is OK (not all phases have research) — only validate if present
    - Error for missing required sections in existing files; warning for missing files in research-type phases

    Follow existing codebase patterns:
    - `const { extractFrontmatter } = require('./frontmatter') as { extractFrontmatter: ... }`
    - `import type { ValidationResult, PlanArtifact } from './types'`
    - Prefix unused params with `_`
  </action>
  <verify>npm run build:check && npm run lint</verify>
  <done>lib/invariants.ts exists with all 5 functions exported, TypeScript compiles, lint passes</done>
