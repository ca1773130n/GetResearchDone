<objective>
Define TraversalOptions and TraversalResult interfaces and implement traverseCitationGraph (BFS traversal with cycle detection, depth/node limits) and resolveTransitiveDeps (merge transitive discoveries into a CitationGraph) in lib/citations.ts.

Purpose: BFS citation traversal is the foundational capability for Phase 97. Once nodes in the direct citation graph are identified, traversal walks edges transitively to discover papers that are dependencies-of-dependencies. Cycle detection and configurable limits prevent unbounded traversal on real citation chains.

Output: Two new exported functions in lib/citations.ts, two new interfaces in lib/types.ts, and 12 new unit tests in the TDD RED-GREEN cycle.

Research basis: Standard BFS with a visited set for cycle detection (Cormen et al., CLRS). Depth and node-count limits are analogous to NERFIFY's ROI windowing — cut off traversal when the marginal value of deeper nodes falls below a threshold.
</objective>

    Import TraversalOptions and TraversalResult types at the top of lib/citations.ts (alongside existing imports from './types').

    **Implement traverseCitationGraph(graph: CitationGraph, options?: Partial\<TraversalOptions\>): TraversalResult**

    - Merge options with defaults: `{ max_depth: 3, max_nodes: 50, ...options }`
    - Build an adjacency map: `Map<slug, CitationEdge[]>` for fast edge lookup
    - BFS queue entries are `{ node: CitationNode, depth: number }`
    - Use a `visited: Set<string>` to track visited slugs — skip any slug already in visited
    - Seed the BFS with ALL nodes in graph.nodes that have no incoming edges (root nodes). If graph.nodes is empty, return empty TraversalResult immediately.
    - For each dequeued `{ node, depth }`:
      - Add to visited_nodes
      - Increment total_visited
      - If total_visited >= max_nodes: stop processing queue
      - If depth >= max_depth: do not enqueue children (but count this node)
      - Look up outgoing edges for this node's slug in the adjacency map
      - If no outgoing edges AND node.resolved === false: add to unresolved_leaves
      - For each outgoing edge: if target slug not in visited and total_visited < max_nodes, enqueue `{ node: targetNode, depth: depth + 1 }` and add edge to edges_traversed
    - Track depth_reached as the maximum depth value seen across all dequeued entries
    - Return TraversalResult with all accumulated values

    **Implement resolveTransitiveDeps(graph: CitationGraph, options?: Partial\<TraversalOptions\>): CitationGraph**

    - Call traverseCitationGraph(graph, options) to get TraversalResult
    - Build a set of existing slugs in graph.nodes
    - Create a new nodes array: graph.nodes + any visited_nodes whose slug is not already in the set
    - Create a new edges array: graph.edges + any edges_traversed that are not already in graph.edges (deduplicate by from_slug + to_slug + component_name)
    - Return a new CitationGraph with the merged nodes, merged edges, and updated built_at timestamp
