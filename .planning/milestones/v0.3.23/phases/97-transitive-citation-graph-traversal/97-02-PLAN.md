<objective>
Implement fetchExternalPaper in lib/citations.ts (arXiv/Semantic Scholar auto-retrieval for unresolved transitive nodes) and add checkTransitiveCitationGate to lib/gates.ts (warning-severity gate that detects unresolved transitive dependencies when transitive_citation_gate is enabled).

Purpose: Wave 1 finds the transitive dependency graph. Wave 2 makes that graph actionable: (1) auto-retrieval attempts to resolve newly-discovered transitive nodes by querying external APIs, and (2) the gate warns researchers when transitive unresolved dependencies exist — without blocking progression (warning vs. error).

Output: fetchExternalPaper exported from lib/citations.ts, checkTransitiveCitationGate exported from lib/gates.ts and wired into GATE_REGISTRY, transitive_citation_gate config key registered end-to-end, 6 new tests passing.

Research basis: The injectable fetchFn pattern established in Phase 93 (resolveCitations) is extended here. Using the same arXiv-first, Semantic-Scholar-fallback strategy as resolveCitations, applied to a single node at a time. Warning (not error) severity follows the principle that transitive dependencies are informational — they don't block a researcher from planning a phase, they inform what additional work may be needed.
</objective>

    ```ts
    function checkTransitiveCitationGate(cwd: string, _opts: GateOptions): GateViolation[] {
      const violations: GateViolation[] = [];
      const config: GrdConfig = loadConfig(cwd);
      const enabled = (config as unknown as Record<string, unknown>).transitive_citation_gate === true;
      if (!enabled) return violations;

      const researchDir = path.join(cwd, '.planning', 'research');
      const papersPath = path.join(researchDir, 'PAPERS.md');
      try { fs.statSync(papersPath); } catch { return violations; }

      try {
        const graph = buildCitationGraph(researchDir);
        const { traverseCitationGraph } = require('./citations') as {
          traverseCitationGraph: (g: CitationGraph, opts?: Partial<TraversalOptions>) => TraversalResult;
        };
        const result = traverseCitationGraph(graph);
        for (const node of result.unresolved_leaves) {
          violations.push({
            code: 'CITATION_UNRESOLVED_TRANSITIVE',
            severity: 'warning',
            message: `Transitive citation dependency "${node.slug}" is unresolved — consider running auto-retrieval`,
            fix: 'Enable transitive auto-retrieval or manually add a PAPERS.md entry for this dependency',
            context: { slug: node.slug, priority: node.priority },
          });
        }
      } catch {
        // Non-blocking
      }
      return violations;
    }
    ```
