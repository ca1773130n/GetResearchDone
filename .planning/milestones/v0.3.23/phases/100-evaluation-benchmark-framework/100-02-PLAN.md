<task type="auto">
  <name>Task 2: Implement classification, scoring, trainability, and evaluation functions (GREEN)</name>
  <files>lib/benchmark.ts</files>
  <action>
    Implement four new functions in lib/benchmark.ts:

    **classifyEntry(entry: BenchmarkEntry): IntegrationCategory**
    Adapted from NERFIFY-BENCH Figure 7 categorization:
    - Check tags array (case-insensitive) against category indicator sets
    - Priority order (first match wins):
      1. 'out-of-scope': tags contain 'hardware-specific', 'proprietary-data', or 'closed-source'
      2. 'requires-external-models': tags contain 'pretrained', 'foundation-model', 'external-weights', or 'fine-tuned'
      3. 'novelty-coverage': tags contain 'novel-loss', 'novel-architecture', or 'novel-representation'
      4. 'directly-integrable': default when no other category matches
    - Return the matched IntegrationCategory

    **scoreSemanticFromSummary(summary: string): SemanticScore**
    - Parse structured evaluation summary text for score fields
    - Look for lines matching `novelty_capture: X.XX`, `api_surface_match: X.XX`, `algorithmic_fidelity: X.XX`
    - Extract numeric values, clamp each to [0, 1]
    - Extract `notes: ...` line content if present (empty string otherwise)
    - If summary is empty or no scores found, return all zeros with empty notes

    **assessTrainability(buildOutput: string, runOutput: string, stderr: string, executionTimeMs: number): TrainabilityMetrics**
    - build_success: buildOutput does not contain error indicators ('error', 'Error', 'FAILED', 'failed to compile')
      AND buildOutput is not empty (empty = no build attempted = false)
    - runtime_stable: runOutput does not contain crash indicators ('SIGKILL', 'SIGSEGV', 'heap out of memory', 'fatal error', 'unhandled exception')
      AND runOutput is not empty
    - convergence_detected: runOutput contains convergence indicators ('converged', 'loss decreased', 'metric improved', /loss:\s*[\d.]+.*→\s*[\d.]+/)
    - execution_time_ms: pass through the executionTimeMs parameter
    - error_log: stderr content (trimmed), empty string if null/undefined

    **evaluateEntry(entry: BenchmarkEntry, semanticSummary: string, buildOutput: string, runOutput: string, stderr: string, executionTimeMs: number, rubricVersion: string, evaluator: string): BenchmarkResult**
    - Classify: if entry.category is already set, use it; otherwise call classifyEntry(entry)
    - Score semantic: call scoreSemanticFromSummary(semanticSummary)
    - Assess trainability: call assessTrainability(buildOutput, runOutput, stderr, executionTimeMs)
    - Compute composite: call scoreComposite(semantic, trainability, createDefaultRubric(), category)
    - Return BenchmarkResult with all fields populated, evaluated_at = new Date().toISOString()

    Add all four functions to module.exports.

    Run tests — they MUST all pass (GREEN phase). Run npm run lint and npm run build:check.
  </action>
