<task id="01" type="auto" tdd="false">
  <name>Add GoT execution types to lib/types.ts</name>
  <description>
  Add the following interfaces to lib/types.ts in a new section "GoT Execution Types (from got.ts)":

  1. **FrozenInterface** — Represents a frozen contract for an artifact:
     - `plan_id: string` — Plan that provides this artifact
     - `artifact: string` — Artifact name (e.g. "lib/foo.ts:Bar")
     - `contract: string` — The frozen interface definition as a string comment

  2. **NodeExecutionResult** — Result of executing a single DAG node:
     - `node_id: string` — The plan node ID (e.g. "98-01")
     - `success: boolean` — Whether execution succeeded
     - `artifacts_produced: string[]` — List of artifact names actually produced
     - `error?: string` — Error message if failed

  3. **SmokeTestResult** — Result of smoke-testing a node's output:
     - `node_id: string` — The plan node ID
     - `passed: boolean` — Whether all provides artifacts were produced
     - `missing_artifacts: string[]` — Provides artifacts NOT in artifacts_produced
     - `message: string` — Human-readable result message

  4. **GoTExecuteOptions** — Options for executeArtifactDAG:
     - `maxRetries?: number` — Max retry attempts per node on smoke failure (default 1)
     - `dryRun?: boolean` — When true, return stub results without dispatching agents

  5. **GoTExecutionResult** — Full result of executing an artifact DAG:
     - `waves: string[][]` — Topological wave groupings of plan IDs
     - `results: NodeExecutionResult[]` — Per-node execution results
     - `smoke_tests: SmokeTestResult[]` — Per-node smoke test results
     - `retries: number` — Total retry count across all nodes
     - `success: boolean` — True when all smoke tests passed

  6. **NodePromptContext** — Context passed to buildNodePrompt:
     - `phase_name: string` — Phase name
     - `phase_dir: string` — Phase directory path
     - `research_dir?: string` — Research directory path (optional)

  Place these after the existing ArtifactDAGValidation interface, before the Gate Types section.
  Export them all (they already are by default since types.ts uses `export interface`).
  </description>
  <done_criteria>
  - All 6 interfaces added to types.ts
  - `npm run build:check` passes (type-checks clean)
  - `npm run lint` passes
  </done_criteria>
</task>
