<objective>
Implement the GoT synthesis execution engine in lib/got.ts and wire buildWavesFromPlans into lib/autopilot.ts.

The execution engine takes an ArtifactDAG (from deps.ts), groups nodes into topological waves, builds execution prompts with frozen interface contracts, and verifies output via smoke tests with a retry loop.

The actual agent spawning is NOT implemented here — that is the caller's (autopilot's) responsibility. executeArtifactDAG operates in "dry-run" mode by default, returning stub results.

Output: lib/got.ts with 4 exported functions + buildWavesFromPlans added to autopilot.ts.
</objective>

<task id="04" type="auto" tdd="false">
  <name>Implement executeArtifactDAG</name>
  <description>
  Implement `executeArtifactDAG(dag: ArtifactDAG, options?: GoTExecuteOptions): GoTExecutionResult`:

  Main orchestration function. Groups nodes into topological waves, then processes each wave:

  1. **Group nodes into waves** using the DAG's sorted_plans and edge structure:
     - Use Kahn's algorithm on the DAG edges to produce wave groupings
     - Wave 0: nodes with in-degree 0 (no requires dependencies)
     - Wave N: nodes whose ALL requires-dependencies are in waves < N
     - Store as `waves: string[][]`

  2. **Freeze interfaces**: Call `freezeInterfaces(dag)` once upfront

  3. **Process each wave sequentially**:
     For each node in the wave:
     a. Build prompt via `buildNodePrompt(node, frozenInterfaces, ...)`
     b. "Execute" the node:
        - In dryRun mode (default): create a stub NodeExecutionResult with
          `success: true` and `artifacts_produced` = node.provides
        - The actual dispatch hook is NOT implemented (deferred to integration phase)
     c. Run `runSmokeTest(node, result)`
     d. If smoke test fails AND retries < maxRetries:
        - Increment retry counter
        - Re-execute the node (same dry-run stub)
        - Re-run smoke test
     e. Collect results and smoke_tests

  4. **Return GoTExecutionResult**:
     - waves, results, smoke_tests, retries count
     - success: true only if ALL smoke tests passed

  Default options: `{ maxRetries: 1, dryRun: true }`
  </description>
  <done_criteria>
