<task type="auto">
  <name>Task 2: Implement refinement functions (GREEN) and add coverage threshold</name>
  <files>lib/refinement.ts, jest.config.js</files>
  <action>
    Implement all five functions in lib/refinement.ts:

    **collectMetrics(testOutput: string, tscOutput: string, lintOutput: string): RefinementMetrics**
    - Parse test coverage from Jest output: look for "All files" line with coverage %, extract Stmts or Lines percentage
    - Parse type error count from tsc output: count lines matching /error TS\d+/
    - Parse lint violation count from eslint output: count lines matching /\d+ problems?/ or individual error/warning lines
    - Return RefinementMetrics with current ISO timestamp

    **detectMinima(snapshots: MetricSnapshot[]): MinimaRegion[]**
    - Adapted from NERFIFY PSNR-minima ROI analysis to GRD domain
    - For test_coverage_pct: find local minima (dips) — indices where coverage is lower than both neighbors
    - For type_error_count and lint_violation_count: find local maxima (spikes) — indices where count is higher than both neighbors
    - Return array of MinimaRegion objects sorted by absolute delta descending (worst regions first)
    - Edge case: arrays with fewer than 3 snapshots return empty (need neighbors)

    **checkConvergence(snapshots: MetricSnapshot[], config: ConvergenceConfig): { converged: boolean, reason: string }**
    - Requires at least 2 snapshots; returns { converged: false, reason: 'insufficient data' } otherwise
    - If snapshots.length >= config.max_iterations: return { converged: true, reason: 'max iterations reached' }
    - Compute delta between last two snapshots for each dimension
    - Converged when: |delta_coverage| < epsilon_coverage AND |delta_type_errors| < epsilon_type_errors AND |delta_lint| < epsilon_lint
    - Return reason string describing which dimensions are still changing if not converged

    **classifyBranch(current: RefinementMetrics, targets: RefinementMetrics): CritiqueBranch**
    - Compute normalized gap for each dimension: (target - current) / target for coverage (higher is better), (current - target) / max(current, 1) for errors/violations (lower is better)
    - Return 'macro' if coverage gap is largest (metric-minima guided patching)
    - Return 'geometry' if type error gap is largest (structural validation)
    - Return 'generative' if lint gap is largest (artifact analysis)
    - Tie-break order: macro > geometry > generative

    **buildCritiquePrompt(branch: CritiqueBranch, metrics: RefinementMetrics, targets: RefinementMetrics, minimaRegions: MinimaRegion[]): string**
    - Build a structured prompt string for the critique agent
    - Include: branch type, current metrics, target metrics, top 3 minima regions
    - For 'macro': emphasize coverage recovery tactics
    - For 'geometry': emphasize type error resolution
    - For 'generative': emphasize lint pattern analysis


    Run tests — they MUST all pass (GREEN phase). Run npm run lint and npm run build:check.
