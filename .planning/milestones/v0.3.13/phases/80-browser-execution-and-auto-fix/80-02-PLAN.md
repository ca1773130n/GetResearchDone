<objective>
Implement auto-fix capability with sonnet-tier model ceiling, confidence gating, and re-run verification.

Purpose: High-confidence missing connections (missing import, unregistered route, missing export) can be fixed automatically by a sonnet-tier agent, then verified by re-running the failed scenario. Low-confidence issues are surfaced for manual review rather than risking incorrect automated changes. This closes the loop between detection and resolution.

Output: `autoFixIssue()`, `updateFixOutcome()`, and `classifyFixConfidence()` functions in `lib/wireup.ts`.
</objective>

  <action>
    Add auto-fix infrastructure to `lib/wireup.ts`:

    1. **Define the SONNET_MODEL constant** (same pattern as `lib/evolve/state.ts`):
       ```typescript
       const WIREUP_FIX_MODEL: string = 'sonnet';
       ```

    2. **Define types:**
       ```typescript
       interface MissingConnection {
         issue_type: 'missing-route' | 'unconnected-handler' | 'missing-import' | 'missing-middleware' | 'broken-nav-link' | 'missing-env-var' | 'missing-export';
         source_file: string;
         target_file: string;
         suggested_fix: string;
         confidence: 'high' | 'medium' | 'low';
       }

       interface FixAttempt {
         issue: MissingConnection;
         fix_status: 'verified' | 'failed' | 'skipped';
         fix_description?: string;
         rerun_passed?: boolean;
         error?: string;
       }

       interface AutoFixResult {
         fixes_applied: FixAttempt[];
         requires_manual_review: MissingConnection[];
         model_used: string;
       }
       ```

    3. **`classifyFixConfidence(issue: MissingConnection): 'high' | 'medium' | 'low'` function:**
       - High confidence (safe to auto-fix): `missing-import`, `missing-export`, `missing-route` (when source and target files exist and the fix is a single-line addition)
       - Medium confidence: `unconnected-handler`, `missing-middleware` (may require understanding of app structure)
       - Low confidence: `broken-nav-link`, `missing-env-var` (may require external configuration or user input)
       - Return the confidence level based on `issue.issue_type`

    4. **`autoFixIssue(cwd, issue, reRunFn)` function:**
       - Takes the `MissingConnection`, a `reRunFn: () => Promise<boolean>` callback that re-runs the failed scenario
       - **Guard:** If `issue.confidence !== 'high'`, return `{ ...issue, fix_status: 'skipped' }` immediately — do NOT attempt fix
       - **Build fix prompt:** Create a structured prompt describing the issue, source file, target file, and suggested fix. The prompt instructs the sonnet-tier agent to:
         - Read the source and target files
         - Apply the minimal fix (add import, register route, add export)
         - Commit with message `wireup: fix <description>`
       - **Important:** The actual fix application is delegated to the wireup orchestrator agent (which spawns a sonnet subagent). `autoFixIssue()` returns the structured prompt and fix metadata — it does NOT spawn subprocesses directly. The orchestrator calls `reRunFn` after the fix agent completes.
       - **Record outcome:** Return a `FixAttempt` with `fix_status` set to `'verified'` if reRunFn returns true, `'failed'` if it returns false

    5. **`buildAutoFixPrompt(issue: MissingConnection): string` helper:**
       - Generates the sonnet-tier agent prompt from the issue structure
       - Includes: issue type, source file path, target file path, suggested fix text
       - Instructs: "Apply the minimal fix. Do not refactor. Commit with message: wireup: fix <description>"

    6. **`updateFixOutcome(cwd, scenarioId, fixAttempt)` function:**
       - Read wireup state from WIREUP-STATE.json
       - Add the fix attempt to the `fixes_applied` array in state
       - Increment `fixes_applied` counter
       - Write updated state back to disk

    7. **`partitionByConfidence(issues: MissingConnection[]): AutoFixResult` function:**
       - Split issues into two groups: high-confidence (attempted for auto-fix) and medium/low-confidence (manual review)
       - Return `AutoFixResult` with `fixes_applied` (initially empty, populated after fix attempts), `requires_manual_review` (medium + low confidence issues), and `model_used: WIREUP_FIX_MODEL`

    8. Export all new functions and types from the module.

    Follow the codebase convention: typed require for imports, `'use strict'` at top, no `any` types.
