<task type="auto">
  <name>Task 1: Implement wireup state read/write/advance functions</name>
  <files>lib/wireup/state.ts</files>
  <action>
    Create `lib/wireup/state.ts` following the exact pattern from `lib/evolve/state.ts`:
    - `'use strict'` at top, JSDoc module header with `@dependencies ./types, ../utils`
    - Import `WireupState`, `WireupIterationHistory` from `./types`
    - Import `safeReadFile` from `../utils` using typed require pattern
    - Import `fs` and `path` from Node built-ins

    **Constants:**
    - `WIREUP_STATE_FILENAME = 'WIREUP-STATE.json'`
    - State file lives at project root alongside EVOLVE-STATE.json: `path.join(cwd, '.planning', WIREUP_STATE_FILENAME)`

    **1. `wireupStatePath(cwd: string): string`** (private)
    - Returns `path.join(cwd, '.planning', WIREUP_STATE_FILENAME)`

    **2. `createInitialWireupState(milestone: string): WireupState`** (public)
    - Returns a fresh WireupState:
      ```
      {
        features_discovered: 0,
        scenarios_generated: 0,
        scenarios_passed: 0,
        scenarios_failed: 0,
        fixes_applied: 0,
        iteration_history: [],
        timestamp: new Date().toISOString(),
        milestone,
      }
      ```

    **3. `readWireupState(cwd: string): WireupState | null`** (public)
    - Read WIREUP-STATE.json using safeReadFile
    - If file does not exist or is unreadable, return `null`
    - Parse JSON and return as WireupState
    - If JSON parse fails, return `null` (graceful degradation)

    **4. `writeWireupState(cwd: string, state: WireupState): void`** (public)
    - Create parent directory with `fs.mkdirSync({ recursive: true })`
    - Write `JSON.stringify(state, null, 2) + '\n'` to the state file path
    - Match the exact pattern from `lib/evolve/state.ts` writeEvolveState

    **5. `advanceWireupIteration(state: WireupState, results: { scenarios_run: number; passed: number; failed: number; fixes_applied: number }): WireupState`** (public)
    - Create a new WireupIterationHistory entry:
      ```
      {
        iteration: state.iteration_history.length + 1,
        timestamp: new Date().toISOString(),
        scenarios_run: results.scenarios_run,
        passed: results.passed,
        failed: results.failed,
        fixes_applied: results.fixes_applied,
      }
      ```
    - Return a new WireupState with:
      - `scenarios_passed` incremented by `results.passed`
      - `scenarios_failed` incremented by `results.failed`
      - `fixes_applied` incremented by `results.fixes_applied`
      - `iteration_history` with the new entry appended
      - `timestamp` updated to current ISO string
    - Do NOT mutate the input state — return a new object (immutable pattern)

    **module.exports:**
    ```
    module.exports = {
      createInitialWireupState,
      readWireupState,
      writeWireupState,
      advanceWireupIteration,
    };
    ```

  <done>
    readWireupState, writeWireupState, advanceWireupIteration, createInitialWireupState all implemented,

  </done>
