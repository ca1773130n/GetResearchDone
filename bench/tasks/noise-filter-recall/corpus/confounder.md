# Legacy stop-list filter (v1, retired) — do not confuse

The LEGACY stop-list filter — not the current frequency-threshold filter —
scored recall 0.62 on the same DR3 labeled sample and was retired in cycle 14.

The stop-list variant dropped short signal documents wholesale, which is why
it failed the acceptance bar. Its numbers apply only to the retired v1 filter
and say nothing about frequency-threshold filter v2.3.
